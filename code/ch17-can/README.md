# 17장 실습: MCP2515로 CAN 통신

| 폴더 | 내용 |
| --- | --- |
| `common/mcp2515.c` | MCP2515 드라이버 (16장의 `spi.h` 위에서 동작): 비트 타이밍 계산, 루프백/노멀 모드, 송수신, 오류 카운터 |
| `common/app.c` | 루프백 자체 시험 → 노멀 모드에서 0.5초마다 송신, 받은 프레임 출력, 5초마다 TEC/REC 출력 |
| `avr/`, `stm32/` | 보드별 main과 Makefile. SPI 구현은 16장 것을 그대로 쓴다 |
| `test/` | 비트 타이밍 계산 호스트 테스트 (`make test`) |

두 보드를 CAN 버스로 연결하고 `NODE_ID`를 다르게 빌드하면 서로의 프레임이 보입니다.

```bash
cd avr   && make flash NODE_ID=0x100
cd stm32 && make flash NODE_ID=0x200
```

모듈의 크리스털이 16 MHz라면 `MCP_OSC_HZ=16000000`을 넘기세요. 버스 양 끝에 120 Ω 종단이 필요합니다(모듈의 J1 점퍼 등). 전원과 논리 레벨은 17.7절을 확인하세요.
