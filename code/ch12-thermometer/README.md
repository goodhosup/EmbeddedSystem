# 12장 프로젝트: 디지털 온도계

아두이노 우노와 TMP36 온도 센서로 만드는 디지털 온도계입니다. 제2부(6~11장)에서 배운 GPIO, 인터럽트, 타이머, ADC를 하나의 프로그램으로 묶습니다.

| 파일 | 역할 |
| --- | --- |
| `avr/main.c` | 요구사항, 상태 머신, 주기 작업 |
| `avr/tick.c` | 1 ms 틱 (Timer0) |
| `avr/button.c` | 디바운싱, 짧게/길게 누름 |
| `avr/sensor.c` | TMP36, 내부 1.1 V 기준 ADC, 16회 평균 |
| `avr/uart.c` | 9600 bps 송신 (14장에서 자세히) |

```bash
cd avr
make flash
# 시리얼 모니터: 9600 bps
```

내부 기준 전압은 칩마다 1.0~1.2 V로 다릅니다. 우노의 AREF 핀 전압을 멀티미터로 잰 뒤 `make flash VREF_MV=1085`처럼 넣으면 측정이 정확해집니다.

STM32로 옮기는 것은 이 장의 연습 문제입니다.
