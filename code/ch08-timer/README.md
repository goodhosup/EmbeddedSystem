# 8장 실습: 타이머와 PWM

| 폴더 | 보드 | 내용 |
| --- | --- | --- |
| `avr/` | 아두이노 우노 | Timer0 1 ms 틱, Timer2 PWM으로 D11 LED 밝기, Timer1으로 D9 서보 |
| `stm32/` | NUCLEO-F411RE | SysTick 1 ms 틱, TIM2 PWM으로 LD2 밝기, TIM3으로 PA6 서보, TIM4 입력 캡처(PB6) |

버튼을 누를 때마다 LED 밝기와 서보 각도가 다섯 단계를 돌아갑니다. 버튼은 5 ms마다 읽어서 20 ms 동안 같은 값이 유지될 때만 인정합니다(7장의 디바운싱 3번 방법).

> 서보 모터는 움직일 때 수백 mA를 쓰므로 보드의 5 V 핀이 아니라 별도 전원(예: AA 건전지 4개, 또는 5 V 2 A 어댑터)에 연결하고, GND만 보드와 공통으로 연결하세요.

STM32 예제에서 PA6(D12)과 PB6(D10)을 점퍼선으로 연결하면, TIM4 입력 캡처가 서보 펄스 폭을 µs 단위로 재서 `pulse_width_us` 변수에 넣습니다. GDB에서 `print pulse_width_us`로 확인합니다.
