# 25장 실습: 메모리 들여다보기

스택 칠하기(최고 수위 측정), MPU 스택 가드, 힙 단편화, 고정 크기 메모리 풀, 구조체 패딩을 확인하는 예제입니다.

```bash
cd test && make          # 메모리 풀과 구조체 배치 PC 테스트
cd stm32 && make flash   # NUCLEO-F411RE, 터미널 115200 bps
```

| 명령 | 하는 일 |
| --- | --- |
| `w` | 스택 최고 수위와 힙 사용량 |
| `d` | 재귀 20단계 뒤 최고 수위 |
| `o` | 끝없는 재귀 → MPU 가드(0x2001 DF00, 256 B)에 닿아 MemManage 폴트 |
| `f` | 힙 단편화 실험 |
| `p` | 메모리 풀 (8개 블록) |
| `a` | 구조체 크기와 멤버 위치 |

이 예제는 자기만의 `_sbrk()`를 정의해 힙이 가드 영역 앞에서 멈추게 합니다(공통 `syscalls.c`의 `_sbrk`는 weak).
