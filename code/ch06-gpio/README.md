# 6장 실습: GPIO

| 폴더 | 보드 | 내용 |
| --- | --- | --- |
| `avr/` | 아두이노 우노 | D2 버튼을 누를 때마다 D13 LED 반전 |
| `stm32/` | NUCLEO-F411RE | B1(PC13) 버튼을 누를 때마다 LD2(PA5) 반전 |

`make SPEED=1`로 빌드하면 LED 핀을 가능한 한 빨리 반전시키는 시험 버전이 됩니다. 오실로스코프나 로직 애널라이저로 핀의 주파수를 재서 두 칩을 비교합니다.

버튼의 바운싱 때문에 한 번 눌렀는데 LED가 두 번 이상 바뀔 수 있습니다. 7장에서 해결합니다.
