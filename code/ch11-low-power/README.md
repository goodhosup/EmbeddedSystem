# 11장 실습: 저전력

| 폴더 | 보드 | 내용 |
| --- | --- | --- |
| `avr/` | ATmega328P (우노 또는 브레드보드) | 파워다운 슬립, 워치독 인터럽트로 1초마다 깨기, D2 핀 변화로 깨기 |
| `stm32/` | NUCLEO-F411RE | Stop 모드, RTC 웨이크업 타이머로 2초마다 깨기, B1 버튼 EXTI로 깨기 |

## 전류 측정

- 우노는 보드의 다른 부품(USB 변환 칩, 레귤레이터, 전원 LED) 때문에 칩이 잠들어도 수십 mA가 흐릅니다. 칩만의 전류는 ATmega328P를 브레드보드에 따로 꽂아 잽니다(11.6절).
- NUCLEO는 JP6(IDD) 점퍼를 빼고 그 자리에 멀티미터를 연결하면 STM32만의 전류를 잴 수 있습니다.

## 디버깅 주의

STM32가 Stop 모드에 들어가면 디버거 연결이 끊깁니다. 다시 업로드가 안 되면 5장의 connect under reset 방법을 씁니다.
