# 7장 실습: 외부 인터럽트와 디바운싱

| 폴더 | 보드 | 인터럽트 |
| --- | --- | --- |
| `avr/` | 아두이노 우노 | INT0 (D2), 하강 에지 |
| `stm32/` | NUCLEO-F411RE | EXTI 라인 13 (B1, PC13), 하강 에지 |

두 예제 모두 ISR은 플래그만 세우고 인터럽트를 잠시 막으며, 메인 루프가 LED를 반전한 뒤 약 20 ms가 지나면 다시 허용합니다. 버튼을 10번 누르면 LED가 꺼지고 처음부터 셉니다.

AVR 예제는 `util/atomic.h`의 `ATOMIC_BLOCK` 매크로가 GNU C 확장을 쓰기 때문에 `-std=gnu11`로 빌드합니다.
