# 설계 문서: 보안 OTA를 갖춘 IoT 센서 노드

40장 최종 프로젝트의 설계 문서입니다. 형식은 30장의 DESIGN.md와 같습니다.

## 1. 목적

실내 온도를 10초마다 재서 클라우드(MQTT 브로커)로 보내는 센서 노드. 현장에 설치한 뒤에도 펌웨어를 원격으로 안전하게 업데이트할 수 있어야 한다.

## 2. 요구 사항

| 번호 | 요구 사항 | 확인 방법 |
| --- | --- | --- |
| R1 | 10초마다 온도(0.01 °C)를 MQTT `nodes/<id>/telemetry`에 JSON으로 발행한다 | 브로커 구독 |
| R2 | 노드와 연결부 사이 UART에서 바이트를 잃거나 깨져도 OTA 조각은 정확히 한 번씩 순서대로 전달된다 | `test/test_link` (0.1% 손실 + 0.1% 깨짐) |
| R3 | 회사의 서명 키로 서명하지 않은 이미지는 노드가 실행하지 않는다 | `ch33 test`, 보드: 다른 키로 서명한 이미지 전송 |
| R4 | 보안 카운터가 낮은 옛 이미지는 실행하지 않는다 | `ch33 test` (롤백) |
| R5 | 새 이미지가 자가 진단(센서, 연결부 응답)을 통과하지 못하고 3번 리셋되면 이전 이미지로 돌아간다 | `ch32 test` (rollback), 보드 |
| R6 | 업데이트 중 어느 순간 전원이 끊겨도 노드는 기존 이미지로 부팅한다 | `ch32 test` (A/B, 전원 차단), 보드 |
| R7 | MQTT와 펌웨어 다운로드는 TLS로 서버를 인증한다 | 다른 인증서의 서버로 접속 시험 |
| R8 | 노드가 멈추면 워치독이 4초 안에 리셋한다 | 35장 방식 |

## 3. 위협 모델 (33장)

| 위협 | 대책 | 남는 위험 |
| --- | --- | --- |
| 네트워크에서 가짜 펌웨어 주입 | 노드가 ECDSA 서명 확인 (R3) | 서명 키 유출 → HSM 보관 |
| 연결부(ESP32) 해킹 | 서명 확인은 노드에서: 연결부는 신뢰하지 않음 | 연결부가 측정값을 위조할 수 있음 |
| 옛 취약 버전으로 되돌리기 | 보안 카운터 (R4) | 카운터 저장소(OTP)를 실습에서는 상수로 대체 |
| 중간자 공격 (MQTT, HTTP) | TLS 서버 인증 (R7) | 장치 인증(클라이언트 인증서)은 확장 과제 |
| 디버그 포트로 Flash 읽기 | 양산 시 RDP 레벨 1 (33장, 36장) | 실험실 수준 공격 |
| UART 선에 장비를 물려 조작 | 서명으로 펌웨어는 보호 | 측정값과 명령은 보호하지 않음 (받아들이는 위험) |

## 4. 하드웨어

| 연결 | STM32 (NUCLEO-F411RE) | ESP32 DevKit |
| --- | --- | --- |
| 링크 TX → RX | PA9 (USART1 TX, D8) | GPIO16 (UART1 RX) |
| 링크 RX ← TX | PA10 (USART1 RX, D2) | GPIO17 (UART1 TX) |
| GND | GND | GND (반드시 공통) |
| BMP280 | I2C1 PB8/PB9 (15장) | |

두 보드 모두 3.3 V 논리이므로 레벨 변환이 필요 없다.

## 5. 소프트웨어

| 구성 | 위치 | 재사용 |
| --- | --- | --- |
| 링크 프로토콜 (COBS + CRC-16 + ARQ) | `common/link.c` | 두 보드가 같은 파일 |
| OTA 쓰기 | `common/ota_writer.c` | 32장 flash_if, bootmeta, bootlogic |
| 보안 부트로더 | `stm32-boot/` | 32장 부트로더 + 33장 secure_verify |
| 노드 앱 | `stm32-node/` | 15장 BMP280, 32장 슬롯 링크, 35장 워치독 |
| 연결부 | `esp32-bridge/` | 20장 Wi-Fi, MQTT/TLS |
| CI | `ch36-cicd/ci/run_host_tests.sh` | 이 프로젝트의 test/를 자동으로 포함 |

## 6. 링크 메시지

| 타입 | 방향 | 데이터 | ACK |
| --- | --- | --- | --- |
| REPORT | 노드 → 연결부 | seq(4), uptime(4), temp_c100(4), 센서 오류(1) | 없음 |
| PING | 연결부 → 노드 | 없음 | 있음 |
| OTA_BEGIN | 연결부 → 노드 | 크기(4), 버전(4) | 있음 (섹터 지우기 후, 시간 제한 4 s) |
| OTA_CHUNK | 연결부 → 노드 | 오프셋(4), 데이터(≤128) | 있음 (200 ms) |
| OTA_END | 연결부 → 노드 | 없음 | 있음 (서명 확인 후, 6 s) |
| ACK / NACK | 양쪽 | 결과 코드(1) | |
