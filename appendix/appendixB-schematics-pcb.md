# 부록 B. 회로도와 PCB 기초

펌웨어 개발자가 회로를 설계할 필요는 없지만, **회로도를 읽을 줄은** 알아야 합니다. 핀이 어디에 연결되었는지, 풀업 저항이 있는지, 전원이 어떻게 들어오는지를 모르면 2장과 6장, 15장에서 본 문제들을 디버깅할 수 없습니다. 그리고 보드 설계 검토에 참여해 펌웨어에 필요한 것(테스트 포인트, 디버그 핀, 부트 핀)을 요청할 수 있어야 합니다(23장, 36장).

## B.1 회로도의 기호

| 기호 | 부품 | 읽을 때 볼 것 |
| --- | --- | --- |
| 지그재그 또는 사각형 | 저항 (R) | 값(10k = 10 kΩ), 풀업인지 풀다운인지 |
| 평행선 두 개 | 커패시터 (C) | 값(100n = 100 nF), 전원 핀 근처의 바이패스인지 |
| 삼각형 + 막대 | 다이오드 (D) | 방향(삼각형 꼭짓점 쪽이 캐소드), LED, TVS, 쇼트키 |
| 삼각형 + 막대 + 화살표 | LED | 직렬 저항이 있는지 (2장) |
| 세 단자 기호 | 트랜지스터, MOSFET (Q) | 부하 스위칭, 레벨 변환 (2장) |
| 사각형 + 핀 이름 | IC (U) | 핀 번호와 이름, 전원 핀이 따로 그려졌는지 |
| 지그재그 코일 | 인덕터 (L), 페라이트 비드 (FB) | 전원 필터 |
| 사각형 + 진동자 기호 | 크리스털 (Y, X) | 주파수, 부하 커패시터 (3장) |
| 아래로 향한 선 묶음 | GND | 아날로그 GND와 디지털 GND가 나뉘었는지 |
| 위로 향한 화살표, 막대 | 전원 (VCC, 3V3, VDD) | 전압 이름 |

문자와 번호(R12, C5, U3)는 **참조 지정자(reference designator)** 로, PCB의 실크(인쇄)와 부품 목록(BOM)에서 같은 이름으로 찾을 수 있습니다.

### 넷과 넷 이름

선으로 직접 이어지지 않아도 **같은 이름표(net label)** 가 붙은 점은 전기적으로 연결된 것입니다. 큰 회로도는 여러 쪽에 나뉘어 있고, 쪽 사이의 연결은 이름표로 합니다. "I2C1_SDA"라는 이름을 회로도 PDF에서 검색하면 MCU 핀, 풀업 저항, 커넥터가 모두 나옵니다. 펌웨어 개발자가 회로도를 읽는 가장 빠른 방법입니다.

선이 교차하는 곳에 **점**이 있으면 연결, 점이 없으면 그냥 지나가는 것입니다.

## B.2 MCU 주변 회로

어느 MCU 보드에나 있는 기본 회로입니다. NUCLEO-F411RE의 회로도(UM1724)를 열어 하나씩 찾아보세요.

**전원과 바이패스 커패시터**: MCU의 전원 핀(VDD)마다 가까이에 100 nF 커패시터가 하나씩, 그리고 근처에 4.7~10 µF 커패시터가 있습니다. 디지털 회로는 클럭마다 순간 전류를 끌어가는데, 전원선의 인덕턴스 때문에 멀리서는 빨리 공급할 수 없으므로 가까운 커패시터가 대신 공급합니다. 아날로그 전원(VDDA)에는 페라이트 비드와 별도의 커패시터로 잡음을 거릅니다(9장의 ADC 정확도). 12장, 30장에서 센서와 SD 카드 옆에 커패시터를 두라고 한 것도 같은 이유입니다.

**리셋 회로**: NRST 핀에 풀업(칩 내부에 있음)과 100 nF 커패시터, 리셋 버튼이 있습니다. 23장의 디버그 프로브도 이 핀을 씁니다.

**부트 핀**: STM32의 BOOT0는 저항으로 GND에 연결되어 평소에는 Flash에서 시작합니다(21장). 32장의 시스템 부트로더를 쓰려면 이 핀을 High로 할 수 있게 점퍼나 테스트 포인트를 둡니다.

**클럭**: 외부 크리스털(HSE)과 부하 커패시터 두 개, 저전력 RTC용 32.768 kHz 크리스털(LSE)이 있을 수 있습니다(3장, 11장). NUCLEO는 ST-LINK가 8 MHz 클럭을 MCU에 공급하는 구성이 기본입니다(29장).

**디버그 커넥터**: SWDIO, SWCLK, NRST, GND, 그리고 전압 감지용 VDD(23장).

## B.3 입출력 회로에서 볼 것

회로도에서 핀 하나를 따라갈 때 확인하는 것들입니다. 이 책의 여러 장과 연결됩니다.

- **풀업/풀다운 저항이 있는가** (6장, 15장): 버튼 입력과 I2C 선에 필요합니다. 보드에 있으면 내부 풀업을 켤 필요가 없고, 없으면 켜거나 달아야 합니다.
- **직렬 저항이 있는가** (2장): LED 전류 제한, 신호선의 링잉 감쇠.
- **전압 레벨이 맞는가** (2장, 16장): 3.3 V MCU와 5 V 장치 사이에 레벨 변환기나 분압 회로가 있는지, 핀이 5 V 허용(FT)인지.
- **보호 소자가 있는가**: 커넥터로 바깥과 이어지는 선에는 정전기(ESD)와 과전압을 막는 TVS 다이오드, 직렬 저항이 있어야 합니다. 없으면 현장에서 고장의 원인이 됩니다.
- **부하를 MCU가 직접 구동하는가** (2장): 모터, 릴레이, 많은 LED는 트랜지스터나 MOSFET, 드라이버 칩을 거쳐야 하고, 유도성 부하에는 역기전력 다이오드가 필요합니다.
- **같은 핀을 둘이 쓰는가** (6장, 16장, 30장): NUCLEO의 PA5가 LD2와 SPI1 SCK에 함께 쓰인 것처럼, 보드의 부품이 이미 핀을 쓰고 있는지 회로도에서 확인합니다.

## B.4 PCB 기초

**PCB(Printed Circuit Board)** 는 회로도를 실제 기판으로 만든 것입니다. 펌웨어 개발자가 알아 두면 좋은 개념만 정리합니다.

**층(layer)**: 간단한 보드는 2층, MCU 보드는 대개 4층(신호 - GND - 전원 - 신호) 이상입니다. 한 층 전체를 GND로 채운 **그라운드 플레인**은 잡음을 크게 줄여 줍니다.

**귀환 경로**: 전류는 신호선으로 갔다가 GND로 돌아옵니다. 돌아오는 길이 멀거나 끊겨 있으면 그 고리가 안테나가 되어 잡음을 내고 받습니다. 그래서 빠른 신호선(SPI 클럭, USB) 바로 아래에는 끊기지 않은 GND 층이 있어야 하고, GND 층을 가로지르는 긴 슬롯을 피합니다. 14장, 16장에서 "선을 짧게, GND를 함께"라고 한 것을 보드 수준에서 지키는 방법입니다.

**배치**: 바이패스 커패시터는 전원 핀 바로 옆, 크리스털은 MCU 클럭 핀 가까이, 스위칭 레귤레이터와 무선 안테나는 아날로그 회로에서 멀리 둡니다.

**배선 폭**: 전류가 큰 전원선과 모터선은 넓게 만듭니다. 폭과 허용 전류의 관계는 IPC-2152 같은 표준과 계산기로 정합니다.

**테스트 포인트와 디버그 핀** (23장, 36장): 양산 시험 지그의 포고 핀이 닿을 수 있게, 전원, GND, SWD, UART, 주요 신호마다 테스트 포인트를 남깁니다. 나중에 덧붙일 수 없으니 펌웨어 개발자가 설계 검토에서 꼭 요청할 항목입니다.

## B.5 도구

**KiCad**는 회로도와 PCB를 설계하는 무료 오픈소스 도구로, 개인 프로젝트부터 상용 제품까지 널리 쓰입니다. 부품 기호와 풋프린트 라이브러리가 풍부하고, PCB 제작 업체에 보낼 거버(Gerber) 파일을 만들어 줍니다. 상용 도구로는 Altium Designer, OrCAD, Cadence Allegro 등이 있습니다.

작은 보드라면 여러 PCB 제작 업체가 소량을 싸고 빠르게 만들어 주며, 부품 실장(PCBA)까지 맡길 수도 있습니다. 첫 보드를 직접 설계해 보는 것은 펌웨어 개발자에게도 하드웨어를 이해하는 가장 좋은 방법입니다. 이 책의 실습을 마쳤다면, 30장의 데이터 로거를 브레드보드 대신 작은 PCB로 만들어 보는 것을 권합니다.

## B.6 회로 검토 체크리스트 (펌웨어 관점)

보드 회로도를 받았을 때 펌웨어 개발자가 확인할 것들입니다.

- [ ] SWD(SWDIO, SWCLK, NRST, GND, VDD)가 커넥터나 테스트 포인트로 나와 있다
- [ ] 디버그 출력용 UART가 나와 있다
- [ ] 부트 핀(BOOT0)을 바꿀 수 있다 (시스템 부트로더로 복구)
- [ ] 사용할 주변장치의 핀 배치가 MCU의 대체 기능 표와 맞다 (데이터시트 핀 표)
- [ ] 같은 핀을 두 기능이 함께 쓰지 않는다
- [ ] I2C에 풀업이 있고, 값이 버스 속도와 선 길이에 맞다 (15장)
- [ ] 외부 장치의 전압 레벨이 맞다
- [ ] 버튼, 커넥터 입력에 보호 소자가 있다
- [ ] 저전력 제품이라면 쓰지 않는 부품의 전원을 끊을 수 있다 (11장, 30장)
- [ ] 외부 크리스털 주파수가 펌웨어의 클럭 설정과 맞다 (3장)
- [ ] 모든 테스트 포인트가 양산 시험 계획과 맞다 (36장)
